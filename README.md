# Thingy:91 X Cellular Air Quality Monitor

A Nordic Thingy:91 X environmental monitoring project based on the work of Paul Kalombo.

## Overview

This project demonstrates how to collect environmental data using the Nordic Thingy:91 X platform and transmit it over a cellular LTE-M connection.

## Features

- LTE-M cellular connectivity
- Environmental sensing

## Hardware

- Nordic Thingy:91 X
- Nordic nRF91 Series SiP
- Integrated environmental sensors
- Onomondo, 1NCE, or equivalent LTE-M/NB-IoT SIM card

## Software

- nRF Connect SDK
- Zephyr RTOS
- Nordic modem firmware
